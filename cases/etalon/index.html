Эталон

О проекте

Что сделали

  • Ролики для окон-экранов
  • Ролик для большого экрана
  • Тест для тачскрина
  • Отправка результата на почту
  • Монтаж на выставке
  • Поддержка

Задача

«Эталон» — одна из самых известных строительных компаний страны: строит жилье и коммерческие объекты по всей России с 1987 года. Для форума 100+ TechnoBuild 2023 нужен был контент для стенда, часть которого сделана в виде жилого дома с экранами вместо окон.

Решение

Мы сделали ролики из жизни в квартире для окон-экранов, тест-опрос на тачскрине и собрали съемки всех комплексов компании для большого экрана.

Каждый ролик в окне начинается и заканчивается закрытыми шторами

Чтобы не делать очень длинные сюжеты, шторы открывались на 30–40 секунд, показывали сценку из жизни квартиры и закрывались обратно. Так окна можно было открывать по очереди и чередовать в них сюжеты.

На тачскрине — тест-опрос: по ответам посетителю подбирается подходящая недвижимость. Результат можно отправить себе на почту: для этого мы запустили на стенде локальный почтовый сервис.
