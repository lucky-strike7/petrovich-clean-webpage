  • Скрипт для After Effects

Задача

Премия РБ с 2018 года отмечает успехи в спорте и букмекерстве, на ее аукционах поддерживают благотворительные проекты. Для церемонии нужен был видеоконтент на три пятиметровых экрана, который дополняет театральное представление.

Решение

Мы анимировали символику премии для номинаций так, чтобы линии бесшовно переходили между экранами, а для сцены с высшим разумом — трехмерные лица.

Ролики для всех номинаций рендерились одной кнопкой

Специально для проекта мы написали скрипт для After Effects, который сразу рендерит ролики для всех номинаций. Это сильно ускорило работу.
